# Sonar

Десктопный плеер, объединяющий музыкальные сервисы: SoundCloud, YouTube Music (с клипами), Spotify,
Яндекс Музыка, Deezer и собственный сервер Navidrome.

## Запуск

    pip install -r requirements.txt
    python main.py

Нужен Python 3.10+ и PyQt6 6.5+ (в нём Qt Multimedia работает через FFmpeg и играет HLS-потоки SoundCloud).

Для YouTube Music нужен ещё Deno: yt-dlp без него не может получить ссылки на потоки YouTube.

    winget install DenoLand.Deno

Приложение ищет deno в PATH, рядом с exe, в папке `bin/` проекта и в `%USERPROFILE%\.deno\bin`.
yt-dlp стоит держать свежим (`pip install -U "yt-dlp[default]"`): YouTube часто меняется.

## Сборка без своего компьютера (GitHub)

В проекте есть .github/workflows/build.yml: GitHub сам собирает Sonar на Windows и выкладывает
архив в Releases.

1. Создайте репозиторий на GitHub (можно приватный) и загрузите туда папку проекта.
2. Если нужен общий сервер Navidrome: Settings → Secrets and variables → Actions → New
   repository secret, имя SHARED_NAVIDROME, значение — содержимое shared_navidrome.json.
   Сам файл в репозиторий не кладите (он в .gitignore).
3. Чтобы выпустить версию: поставьте тег, например v1.2.0
   (git tag v1.2.0 && git push origin v1.2.0, или Releases → Draft a new release → новый тег).
   Минут через 10–15 в Releases появится Sonar-ГГГГММДД.zip — ссылку можно давать людям.
4. Собрать без релиза: Actions → «Сборка Sonar» → Run workflow; архив — в Artifacts.

## Sonar для Linux

Работает на обычных Linux с графическим рабочим столом (Ubuntu, Mint, Debian, Fedora, Arch и т. д.,
x86_64). Релиз на GitHub сам собирает два архива: Sonar-X.Y.Z.zip для Windows и
Sonar-X.Y.Z-linux-x86_64.tar.gz для Linux.

Установка: распакуйте архив куда угодно, в папке запустите ./Sonar. Чтобы Sonar появился в меню
приложений — ./install.sh (убрать — ./install.sh --remove). Если не запускается с ошибкой про
xcb — поставьте библиотеки Qt (команды в ЧИТАЙ-МЕНЯ.txt в той же папке).

В Linux медиакнопки клавиатуры, шторка GNOME/KDE, экран блокировки и playerctl управляют
Sonar через MPRIS. Горячие клавиши из настроек работают, пока окно Sonar активно. Автообновление,
пульт с телефона, Telegram-бот и статус в Discord (обычный, Flatpak и Snap) работают так же.

Собрать самому: python3 build.py — сборщик сам создаст окружение .venv (если пишет про venv:
sudo apt install python3-venv) и положит в dist папку Sonar и архив .tar.gz.

## Sonar для Android

Папка android — отдельное приложение для телефона (Kotlin, Jetpack Compose, Media3). Релиз на
GitHub сам собирает Sonar-X.Y.Z.apk рядом с версиями для Windows и Linux.

Что умеет первая версия: YouTube Music и SoundCloud без входа (через NewPipeExtractor), Navidrome
(общий сервер подключается сам, можно свой), поиск, «Моя волна», лайки, история, бесконечная
волна (похожие треки, когда очередь кончилась), фоновое воспроизведение с уведомлением, экраном
блокировки и кнопками наушников, текст песни (как в Dotify), автообновление из релизов GitHub.

Один раз для подписи APK (иначе телефоны не дадут обновляться поверх): добавьте в секреты
репозитория ANDROID_KEYSTORE_B64 и ANDROID_KEYSTORE_PASSWORD (значения — в файле
android-signing-secrets.txt, который прислал Claude). Общий Navidrome берётся из того же
секрета SHARED_NAVIDROME, что и для ПК.

Установка: скачать APK на телефон и открыть; Android попросит разрешить установку из этого
источника. В Google Play такое приложение не пропустят — раздавайте APK через GitHub/Telegram.

## Знакомство и профиль

При первом запуске (или если имя ещё не указано) открывается экран «Как тебя звать?» на живом
градиенте: карусель аватарок (по центру — выбранная, по бокам — соседние; стрелки, клик по боковой
или ← →) и поле имени. Фон окрашивается в цвета выбранной авы. «Пропустить»
даёт случайное имя вроде «Ламповый Диджей 26» и случайную аву. Аватарка показывается вверху
левого меню; клик по ней — сменить имя или аву. Аватарки лежат в `sonar/assets/avatars`,
список с подписями — в `sonar/profile.py`.

## Если трек не играет

Если трек не заиграл (только для подписчиков, регион, сбой), Sonar ищет его же в других
подключённых сервисах — сначала в тех, что играют своим звуком (Яндекс, Navidrome, YouTube Music,
SoundCloud), затем в Deezer и Spotify — и включает оттуда с уведомлением вроде «„Трек“ не играет
в SoundCloud — включаю из Яндекс Музыки». Совпадение строгое: название, исполнитель и длительность,
ремикс вместо оригинала не подставится. Если и запасной вариант не играет — трек пропускается.
Выключается в Настройки → Визуальное отображение.

Если у исполнителя в сервисе нет альбомов (или профиль не загрузился), на его странице появляются
блоки «Также в …» — альбомы и популярные треки того же исполнителя из других сервисов.

## Поиск на YouTube

Звук Spotify и Deezer, клипы и видео на фоне находятся на YouTube Music по ISRC или исполнителю,
названию и длительности. Сравнение устойчиво к языку: «Кино — Группа крови» совпадает с
«KINO — Gruppa krovi», «Цой» — с Tsoy/Tsoi/Coi; поиск идёт на русском, а если там пусто — на
английском. Ремиксы, концертные версии и каверы другой длины отсеиваются. Если трек не нашёлся,
в журнале видно, что предлагал YouTube и почему не подошло; повторный поиск — через 10 минут.

## Обрывы соединения и журнал

Треки Яндекса скачиваются целиком во временный кеш (`%TEMP%\Sonar\cache`, последние 40 треков)
и играют из файла: при потоковом чтении сервер Яндекса обрывал соединение посреди трека.
Следующий трек очереди подкачивается заранее. Если загрузка оборвалась, она докачивается с места
обрыва. Для остальных сервисов при обрыве Sonar заново получает ссылку и продолжает с того же
места — до трёх раз на трек.

Журнал работы: `%APPDATA%\Sonar\logs\sonar.log` (текущий запуск) и `sonar.prev.log` (прошлый).
В нём события плеера, ошибки, сообщения Qt и FFmpeg, аварийные падения. Настройки → Данные →
«Открыть журнал» / «Сохранить журнал…» (оба запуска в один .txt). В журнале бывают адреса потоков,
у Navidrome в них токен входа — пересылайте только тому, кому доверяете.

## Недоступные треки

Настройки → Данные → «Недоступные треки»: все треки, которые Sonar встретил недоступными (их и прячет
«Скрывать недоступные треки»), по 100 на страницу. Хранится до 1000, новые вытесняют самые старые;
трек, который всё-таки заиграл, из списка убирается.

## Где хранятся данные

Настройки → Данные: сколько скачано и где лежит, путь и объём данных Sonar, кнопки
«Открыть папку загрузок», «Удалить все загрузки», «Открыть папку данных» и «Сбросить всё».

- `%APPDATA%\Sonar` — `config.json` (настройки, сервисы с токенами входа, профиль),
  `history.json`, `likes.json`, `playlists.json`. Не удаляется вместе с программой.
  Токены лежат открытым текстом — не передавайте эти файлы.
- `downloads` рядом с программой — скачанные треки Navidrome.

«Сбросить всё» удаляет данные Sonar (по галочке — и скачанные треки) и перезапускает программу
как при первом запуске.

## Если вход устарел

Когда сервис отклоняет токен (например, SoundCloud через какое-то время), на главной появляется
плашка «вход устарел» с кнопкой «Войти заново», а в Интеграции карточка подсвечивается красным
с той же кнопкой — она сразу открывает окно входа. Client ID Spotify, адрес и логин Navidrome
при повторном входе подставляются сами. Кнопки «Обновить» (в карточке сервиса и под шестерёнкой)
крутят иконку, пока идёт загрузка, и сообщают итог.

## Подключение SoundCloud

Настройки → Интеграция → SoundCloud → «Войти через браузер». Откроется окно с сайтом
SoundCloud: войдите в аккаунт, и оно закроется само, а приложение заберёт cookie `oauth_token`.
Сессия встроенного браузера живёт только в памяти, на диск сохраняется лишь сам токен.

Вход через Google или Apple во встроенном окне может быть заблокирован самим Google:
в этом случае используйте вход по почте и паролю SoundCloud либо «Ввести токен вручную».
Без пакета PyQt6-WebEngine остаётся только ручной ввод. После подключения на главной появятся «Рекомендации»,
«Мне нравится», «Вы недавно слушали», а кнопка «Моя волна» запустит бесконечную перемешанную очередь.

## Подключение YouTube Music

Настройки → Интеграция → YouTube Music → «Войти через браузер», затем вход в аккаунт Google.
Приложение забирает cookie youtube.com. Google иногда блокирует вход во встроенных окнах
(«Этот браузер или приложение могут быть небезопасны»). Тогда откройте «Ввести данные вручную»
и вставьте заголовки запроса из DevTools (инструкция в карточке).

Клипы: правый клик по треку YouTube → «Смотреть клип», или кнопка с камерой в плеере.
Для обычной песни ищется её официальный клип. Двойной клик или F — полный экран, Esc — выход.
Без склейки видео и аудио доступны только потоки со звуком внутри, поэтому качество клипа
часто ограничено 360p; «Открыть на YouTube» откроет его в полном качестве в браузере.

Настройки и токены лежат в `%APPDATA%\Sonar\config.json`.

## Подключение Spotify

Spotify пускает сторонние программы только через ваше собственное приложение разработчика:

1. developer.spotify.com/dashboard → Create app. С 2026 года режим разработки требует
   Spotify Premium у владельца приложения и допускает до 5 пользователей.
2. Redirect URIs: `http://127.0.0.1:8898/callback`, APIs: Web API.
3. В Sonar: Настройки → Интеграция → Spotify → «Настроить», вставьте Client ID, «Войти».

Вход идёт по OAuth PKCE: секрет приложения не нужен, токен обновляется сам.
Spotify отдаёт звук только под DRM, поэтому треки Spotify играют через тот же трек
на YouTube (подбор по ISRC или по исполнителю и названию с проверкой длительности).
Если подходящей версии нет, трек пропускается с уведомлением.
Рекомендации Spotify для новых приложений закрыты, поэтому «Моя волна» для Spotify
собирается из топа, лайков и истории.

## Большой плеер

Клик по обложке или названию в нижнем плеере открывает плеер на всё окно: крупная обложка,
название, перемотка, управление, лайк, «Добавить в плейлист», клип и громкость. Фон —
градиент из цветов текущей обложки и двух производных оттенков: пятна плывут, оттенки
дрейфуют, а пока играет музыка, движение ускоряется и «дышит»; на паузе фон затихает.
При смене трека цвета перетекают к новой обложке. Esc или стрелка вверху сворачивают, пробел — пауза, ← / → — соседние треки.

## Текст песни (караоке)

Кнопка с нотой и строками под большим плеером показывает текст песни вместо обложки. Буквы сначала
белые, а по мере того как их поют, по одной становятся чёрными (с плавной заливкой внутри буквы).
Текущая строка держится по центру. Колёсиком текст можно прокрутить, щелчок по строке перематывает
песню к ней. Тексты берутся из открытой базы LRCLIB (lrclib.net) и сохраняются в папке данных
(`lyrics`), так что повторно и в офлайне открываются сразу. Если у песни есть только текст без
разметки по времени, он показывается целиком, без подсветки. Включённый режим запоминается.

Вид текста настраивается: кнопка с шестерёнкой вверху справа (видна, когда открыт текст) или
Настройки → Плеер → «Текст песни» с живым превью. Есть два вида: «Как в Dotify» (подсвечивается
вся текущая строка) и «Караоке» (по буквам). Можно поменять цвет текста и цвет спетого (или взять
готовую пару), обводку букв, шрифт, размер, жирность, выравнивание, скорость заливки, сдвиг по
времени (если текст спешит или отстаёт) и плавность прокрутки. «Вернуть как было» сбрасывает
только настройки текста.

## Эквалайзер

Кнопка с тремя ползунками в нижней панели, рядом с наушниками. 10 полос от 31 Гц до 16 кГц,
пресеты («Бас», «Больше баса», «Вокал», «Ночь», «Электроника», «Рок», «Хип-хоп», «Акустика»,
«Чёткость»), кривая того, что получилось, и предусилитель «Пред.» — если на громких местах
хрипит, опустите его. Пресеты сами ставят запас громкости. Настройки запоминаются.

Пока эквалайзер выключен или все полосы на нуле, звук идёт как раньше, напрямую. Если на
каком-то компьютере эквалайзер не сможет получить звук из плеера, он выключится сам и
скажет об этом — музыка не пропадёт.

## Итоги года

Кнопка со звёздочкой в левом меню. Сторис-слайды: сколько минут музыки, исполнитель и трек
года, твой ритм (ночная сова или жаворонок, любимый час, самый музыкальный день), любимый
сервис и с чего начался год. Листаются щелчком, сохраняются картинками 1080×1920 — сразу в
сторис или TikTok. Дневник прослушиваний (plays.jsonl) ведётся только на этом компьютере;
то, что было до этой версии, считается примерно по истории.

## Визуализатор, кроссфейд, волна, горячие клавиши

- Визуализатор: в большом плеере фон пульсирует под бас, а по низу бегут полоски спектра.
  Включается в настройках фона (палитра вверху справа или Настройки → Плеер).
- Кроссфейд (Настройки → Плеер): конец трека перетекает в следующий, 0–12 секунд.
- Бесконечная волна: очередь закончилась — Sonar сам добавляет похожие треки.
- Горячие клавиши (Настройки → Плеер): пауза, следующий/предыдущий, громкость, лайк —
  работают, даже когда Sonar свёрнут. Плюс медиакнопки клавиатуры — их Sonar занимает,
  только пока сам играет, на паузе они снова у Spotify и других плееров.
- «Собрать в другом сервисе» на странице плейлиста: те же треки ищутся в выбранном сервисе,
  из найденного собирается новый плейлист Sonar, ненайденные показываются списком.

## Радио, будильник, оверлей, громкость, перевод, умные плейлисты

- Радио — кнопка с глобусом в левом меню: тысячи станций из открытого каталога radio-browser.info,
  жанры, поиск, «Россия» или весь мир, избранное (правый клик по станции).
- Выравнивание громкости (Настройки → Плеер, включено): Sonar измеряет громкость трека и мягко
  подстраивает её к общему уровню (±8 дБ), ползунок не двигается. Запоминает треки.
- Оверлей поверх игр (Настройки → Плеер): плашка с треком в углу экрана — при смене трека или
  всегда; Ctrl+Alt+O показать/спрятать. Не мешает мыши. В эксклюзивном полноэкранном режиме игры
  Windows ничего поверх не показывает — включите в игре «полноэкранный оконный».
- Будильник (Настройки → Плеер): время, дни, что играть (лайки, волна, радио, плейлист), плавное
  нарастание громкости, «Проверить сейчас». Работает, пока Sonar открыт (можно в трее).
- Перевод текста песни: переключатель «Перевод на русский под строками» в настройках текста
  (шестерёнка в большом плеере). Переводы кешируются.
- Умные плейлисты (в «Плейлистах», со звёздочкой): «Лайки за месяц», «Самое заслушанное»,
  «Давно не слушал», «Ночное» — собираются сами.

## Пульт с телефона

Настройки → Данные → «Пульт с телефона»: включите и наведите камеру телефона на QR-код.
Откроется страница-пульт: обложка, трек, перемотка по полоске, пауза, назад/дальше, лайк,
громкость и что играет дальше. Телефон должен быть в той же Wi-Fi сети. Ссылка содержит ключ —
без него пульт не открывается; «Новая ссылка» делает старые недействительными. При первом
включении Windows спросит про доступ к сети — разрешите для частных сетей. Порт 8765–8775.

## Telegram-бот

Свой бот-пульт для каждого. У @BotFather командой /newbot создайте бота, вставьте его токен в
Настройки → Данные → «Telegram-бот» и нажмите «Сохранить и запустить». Затем отправьте боту
/start и код из настроек — с этого момента бот слушается только вас. Команды: /now (что
играет, с обложкой и кнопками ⏮ ⏯ ⏭ 🔉 🔊 ♥), /pause, /next, /prev, /vol 50, /like.
Если Telegram недоступен напрямую — впишите прокси (socks5://… или http://…).
Бот работает, пока открыт Sonar.

## Статус в Discord

Пока играет музыка, в профиле Discord видно «Слушает Sonar»: трек, исполнитель, обложка,
полоска времени и кнопки «Скачать Sonar» и «Telegram». Нужен запущенный Discord на том же
компьютере. Выключается в Настройки → Данные.

Один раз для сборки: на https://discord.com/developers/applications создайте приложение с именем
Sonar (это имя и покажет Discord), скопируйте Application ID и либо впишите его в APP_ID в
sonar/discord_presence.py, либо на GitHub: Settings → Secrets and variables → Actions →
вкладка Variables → New repository variable, имя DISCORD_APP_ID. По желанию в Rich Presence →
Art Assets загрузите картинку с именем sonar — она будет вместо обложки, если обложки нет.

## Обновления

Версия берётся из тега релиза на GitHub (v1.2.0 → 1.2.0). Sonar проверяет релизы при запуске
и раз в 6 часов и предлагает обновиться: скачивает архив, закрывается на пару секунд и
открывается новым. Папки data и downloads (настройки и скачанные треки) не трогаются.
Настройки → Данные → «Обновления»: выключить проверку или проверить сейчас. Сборка без тега
(версия dev) сама не предлагает обновлений.

## Наушники и колонки

Кнопка с картинкой наушников рядом с громкостью показывает, куда сейчас идёт звук, и даёт его
переключить: «Как в системе» или конкретные наушники, колонки, монитор. Картинка устройства
подбирается по названию (вкладыши, полноразмерные, внутриканальные, гарнитура, колонки,
ноутбук, монитор). Если угадано не то — «Мои наушники другие…»: выберите вид или поставьте
своё фото наушников. Выбор запоминается; если наушники отключились, звук идёт туда, куда
система, а когда они вернутся — снова в них.

## Мастерская

Кнопка с палитрой в левом меню. Четыре вкладки:

- «Мои наборы» — «Сохранить текущее оформление» запоминает тему, свои цвета, обои, иконку,
  снег, фон большого плеера и вид текста песни. Набор можно применить, удалить или
  «Поделиться»: сохранить файлом .sonarpack (его открывают кнопкой «Открыть файл набора…»)
  или отправить в общий каталог — откроется заявка на GitHub, к ней нужно прикрепить файл.
  Логины от сервисов и личные данные в набор не попадают.
- «Каталог» — встроенные наборы и наборы из папки workshop в репозитории на GitHub
  (workshop/index.json). Чтобы добавить присланный набор: положите его файл в workshop/
  и допишите запись в index.json (или впишите настройки прямо в запись — пример там есть).
- «Достижения» — 15 приколюх за то, как вы слушаете: ночная сова, меломан, марафон… Считается
  только на этом компьютере.
- «Приколюхи» — конфетти, режим вечеринки (фон плеера сам меняет цвета), «Удиви меня»
  (случайное оформление). А ещё где-то спрятана пасхалка.

## Скачивание и офлайн-режим

Треки Navidrome можно скачать: правый клик → «Скачать для офлайна» («Удалить загрузку» —
обратно). Файлы (оригинал с сервера) и обложки кладутся в папку `downloads` (в портативной
сборке — `data\downloads` рядом с программой), список — в `index.json` там же. Скачанный трек всегда играет из файла.

Офлайн-режим включается в Настройки → Данные (выйти можно и кнопкой на главной): везде (главная, поиск, лайки, история,
свои плейлисты, страница Navidrome) видны только скачанные треки Navidrome, запросов в сеть
нет, поиск идёт по скачанному. Повторное нажатие возвращает онлайн.

## Иконка и обои

Настройки → Темы и оформление, раздел «Оформление» (там же переключатель «Снежинки»: включается
сам с новогодней темой, выключается при уходе из неё, а в любой теме его можно переключить вручную): иконка приложения (панель задач и заголовок окна) — «Стандартная»,
«Новогодняя», «Морская», «Космическая» или «Своя…» из любой картинки; обои главной панели —
«Новогодние», «Морские», «Космос» или «Свои…», с ползунком видимости. Под обоями — «Или выбрать
цвет заднего фона?»: свой цвет для левого меню с нижним плеером и для основной панели (страниц
и настроек). Текст сам становится тёмным или светлым, чтобы читаться; цвет панели заменяет обои. Свои картинки
копируются в `%APPDATA%\Sonar` (`custom_icon.png`, `custom_wallpaper.png`), так что исходный
файл можно удалить или переместить.

## Удобства

- **Горячие клавиши**: пробел — пауза, Ctrl+→/← — треки, Ctrl+↑/↓ — громкость, Ctrl+L — лайк,
  Ctrl+F — поиск, Ctrl+Enter — большой плеер; мультимедийные клавиши клавиатуры и наушников.
  Список — в Настройки → Визуальное отображение.
- **Продолжить с места**: очередь, трек и позиция сохраняются при выходе; после запуска «играть»
  продолжает с той же секунды. Размер и положение окна тоже запоминаются.
- **Значок в трее** с управлением плеером; «Сворачивать в трей при закрытии» — крестик прячет
  окно, музыка играет дальше. Уведомление о новом треке, когда окно свёрнуто или в фоне.
- **Мягкая пауза**: громкость плавно гаснет при паузе и нарастает при старте — без щелчков.
- **Очередь** — кнопка в нижнем плеере: ближайшие треки, клик — перейти к треку.
- **«Скопировать ссылку»** в меню любого трека.
- **Статистика** на странице «Прослушанное»: сколько треков и часов за неделю и кого слушали чаще.
- **Плавные переходы** между страницами и вкладками, уведомления выезжают и растворяются,
  кнопки воспроизведения и лайка «подпрыгивают». Пока применяется тема, акцент или цвет фона,
  окно накрывается размытым снимком с надписью «Применяю настройки».

## Мелочи для души

- **Пластинка**: Настройки → Плеер → «Обложка-пластинка» — обложка становится виниловой
  пластинкой и крутится, пока играет музыка.
- **Сердечки при лайке** разлетаются из кнопки (Настройки → Оформление, можно выключить).
- **Акцентный цвет** (Настройки → Оформление): кнопки воспроизведения, ползунки, переключатели —
  восемь готовых цветов или свой; иконка на кнопке сама становится тёмной или светлой.
- **Таймер сна** — луна в нижнем плеере: через 15–90 минут или после текущего трека громкость
  плавно стихает, музыка встаёт на паузу, громкость возвращается.

## Фон большого плеера

Настройки → Плеер (или кнопка с палитрой вверху справа в самом большом плеере):
цвета — «Из обложки», готовые палитры «Огонь», «Закат», «Океан», «Аврора», «Неон»
(яркие пятна на тёмном фоне) или «Свои» (три цвета на выбор, «Случайные»);
«Размытие» — от чётких бесформенных пятен до мягкого тумана (пятна не круглые: колышутся,
вытягиваются и поворачиваются); «Скорость движения» пятен.
«Видео на фоне» — тот же трек с YouTube (официальный клип, если он есть) беззвучно и в такт
музыке на фоне большого плеера; для любого сервиса трек находится на YouTube по ISRC или
исполнителю и названию. Видео берётся до 720p и только пока открыт большой плеер; ползунок
«Прозрачность видео» — насколько сквозь него проступает градиент. Во вкладке настроек есть живое превью; «Вернуть как было» сбрасывает фон к цветам обложки.

## Мини-плеер и повтор

Когда главное окно свёрнуто, в углу экрана появляется мини-плеер поверх всех окон: обложка,
название, ползунок, повтор, назад, играть/пауза, вперёд и громкость. Его можно перетащить за фон —
позиция запоминается. Клик по обложке или стрелке разворачивает Sonar, крестик скрывает
мини-плеер до следующего сворачивания.

Кнопка повтора есть в нижнем, большом и мини-плеере (состояние общее и запоминается):
трек по окончании начинается заново, очередь не двигается.

Кнопка со стрелками под шестерёнкой обновляет главную мимо кеша; «Обновить плейлисты»
на странице плейлистов заново загружает плейлисты сервисов.

## Общий сервер Navidrome (подключается у всех сам)

Чтобы ваш Navidrome был у всех пользователей Sonar сразу и без пароля:

1. В Navidrome заведите отдельного пользователя для всех, без прав администратора
   (например sonar-guest). Не используйте свою учётную запись.
2. Скопируйте shared_navidrome.example.json в shared_navidrome.json (в корне проекта, рядом
   с build.py) и впишите адрес сервера, имя и пароль этого пользователя.
3. Запустите build.bat. Сборщик положит в программу адрес и токен для входа (сам пароль в exe
   не попадает), а после сборки удалит токен из исходников.

У пользователей Navidrome подключится сам, в настройках будет написано «общий сервер, вход
не нужен». Можно нажать «Свой сервер» и подключить свой вместо общего, или «Отключить»;
вернуть общий — кнопкой «Общий сервер». Сменить сервер без пересборки: положите
shared_navidrome.json рядом с Sonar.exe — он важнее встроенного.

Важно: токен даёт тот же доступ, что и пароль этого пользователя, и при желании его можно
достать из программы. Поэтому только отдельный пользователь без админки; если токен утечёт —
смените пароль этому пользователю в Navidrome и пересоберите Sonar.

## Подключение Яндекс Музыки

Интеграция → Яндекс Музыка → «Войти»: откроется вход в Яндекс, после него окно закроется само
(токен берётся из адреса редиректа). Можно вставить OAuth-токен вручную. На главной —
настоящая «Моя волна» Яндекса и «Мне нравится»; работают поиск и плейлисты. Звук — прямые
файлы Яндекса: полные треки с подпиской Плюс, без неё трек помечается недоступным.
Работает через неофициальную библиотеку `yandex-music`.

## Подключение Deezer

Регистрация новых приложений Deezer закрыта, поэтому без входа: Интеграция → Deezer →
«Подключить», ссылка на свой публичный профиль (deezer.com/ru/profile/…). Лайки и плейлисты
профиля, чарт Deezer, поиск. Потоки Deezer зашифрованы, звук идёт через тот же трек на YouTube
(по ISRC), клипы тоже.

VK Музыку подключить нельзя: VK закрыл API аудио для сторонних программ в 2016 году, а
обходные клиенты выдают себя за официальное приложение VK — за это блокируют аккаунты.

## Подключение Navidrome

Настройки → Интеграция → Navidrome → «Подключить»: адрес сервера (как в браузере, например
`http://192.168.1.10:4533`), имя пользователя и пароль. Подходит любой Subsonic-совместимый
сервер. Пароль не сохраняется: на диске лежит только токен `md5(пароль + соль)` и соль.
На главной: «Избранное», «Новое на сервере», «Случайное с сервера»; поиск и плейлисты тоже
работают. Звук идёт прямым потоком с сервера.

## Исполнители и альбомы

Имя исполнителя у любого трека (в карточках, списках, нижнем и большом плеере) — ссылка: клик
открывает профиль — фото, описание (у кого из сервисов оно есть), популярные треки, альбомы
и синглы от новых к старым с датами выхода. Альбом открывается со списком треков, их можно
слушать целиком или вперемешку; «Назад» возвращает туда, откуда пришли. В левом меню разделы
«Исполнители» (подписки из сервисов и «Из ваших лайков») и «Альбомы» (из библиотеки сервисов).

## Подборки сервисов

Плейлисты самих сервисов — «Плейлист дня», «Премьера» и чарт Яндекса, плейлисты с главной
YouTube Music («Заряд энергии» и т. п.), чарты Deezer, подборки SoundCloud — на странице
«Плейлисты» и на главной в полке «Подборки» (вместе со «Случайные 50»). Обложки — из сервисов,
у плейлистов, созданных в Sonar, — свои цветные. Редакционные подборки Spotify (Top 50 и т. п.)
приложениям в режиме разработки недоступны.

## Плейлисты

Пункт «Плейлисты» в левом меню. «Мои плейлисты» живут только в Sonar и могут смешивать треки
из любых сервисов: правый клик по треку → «Добавить в плейлист» (или «+» в плеере), там же
«Новый плейлист…». Ниже — плейлисты каждого подключённого сервиса, сколько их отдаёт API:
SoundCloud (свои и лайкнутые), YouTube Music (из библиотеки), Spotify (свои и совместные: с 2026
года чужие плейлисты сторонним приложениям не отдаются; после обновления нужно один раз
войти в Spotify заново, чтобы выдать доступ к плейлистам), Navidrome (все плейлисты сервера).
Хранятся в `%APPDATA%\Sonar\playlists.json`.

## Поиск и отображение

Кнопка воспроизведения на картинке «Моей волны» включает случайную подборку до 50 треков
со всей главной, из «Моих лайков» и локальных плейлистов. «Мои лайки» показываются сеткой
или списком (переключатель справа над треками).

Строка поиска вверху главной ищет сразу во всех подключённых сервисах (Enter или пауза
в наборе), Esc или крестик возвращают главную. Недоступные треки затемнены и помечены
«Недоступно»; Настройки → Визуальное отображение → «Скрывать недоступные треки» убирает их
с главной и из поиска.

## Прослушанное

Пункт с иконкой звуковой волны в левом меню: треки, которые вы слушали в Sonar, из всех
сервисов, сгруппированы по дням. Трек попадает сюда, когда реально начал играть; повторное
прослушивание поднимает его наверх. Хранится до 300 треков в `%APPDATA%\Sonar\history.json`.

В поиске группы сервисов сворачиваются кликом по заголовку; свёрнутые группы запоминаются.

## Мои лайки

Пункт с сердечком в левом меню. Лайк ставится сердечком в плеере или через правый клик
по любому треку («Добавить в мои лайки»). Лайки живут только в Sonar (на сервисах ничего
не меняется), поэтому в одной сетке лежат треки из разных сервисов; значок в углу обложки
показывает источник, фильтры сверху оставляют один сервис. Хранятся в
`%APPDATA%\Sonar\likes.json`.

На главной у длинных полок есть стрелки для листания.

## Темы

Настройки → Темы и оформление (выбор темы сбрасывает свои цвета акцента и фона): «Тёмная», «Светлая», «Авто» и «Новогодняя». «Авто» включает светлую тему
днём и тёмную вечером; время переключения задаётся там же («Светлая с», «Тёмная с»,
можно и через полночь), смена происходит сама, без перезапуска. Новогодняя тема
(красно-белая, со снегом, оленями и шапочками) от времени не зависит.
Новая тема — это палитра и флаги декораций в `THEMES` в `sonar/ui/theme.py`.

## Иконки сервисов

Иконки берутся из `sonar/assets/<id сервиса>.png` (`soundcloud.png`, `ytmusic.png`,
`spotify.png`, `navidrome.png`), углы скругляются автоматически. Если файла нет, рисуется плитка с монограммой.

## Сборка exe

Двойной щелчок по `build.bat` (или `python build.py`). Сборщик сам ставит зависимости
и PyInstaller, рисует иконку, собирает `dist\Sonar\Sonar.exe` со всеми данными (аватарки,
иконки сервисов, языковые файлы ytmusicapi, скрипты yt-dlp), кладёт рядом `deno.exe`, если он
установлен, и упаковывает всё в `dist\Sonar-ГГГГММДД.zip`. Параметры: `--no-install`
(не трогать pip), `--no-zip`, `--no-deno`, `--no-portable`.

Сборка **портативная**: рядом с `Sonar.exe` лежит `portable.txt`, и все данные (настройки,
сервисы, профиль, лайки, плейлисты, история, журнал, скачанные треки) хранятся в папке `data`
рядом с программой. Папку `Sonar` можно класть куда угодно — на другой диск, флешку, другой ПК,
под другую учётную запись — и запускать двойным щелчком по `Sonar.exe`. Нет папки `data` —
создаётся новая, как при первом запуске. Если в папку программы нельзя записывать, Sonar не
падает, а хранит данные в профиле пользователя и пишет об этом в Настройки → Данные.
Удалите `portable.txt`, чтобы данные всегда хранились в `%APPDATA%\Sonar`.

С QtWebEngine сборка весит ~200 МБ; `--onedir` запускается заметно быстрее, чем `--onefile`.

## Как добавить сервис

1. Создайте `sonar/services/<имя>.py` с подклассом `MusicService` (см. `base.py`):
   `connect`, `home_sections`, `wave`, `stream_url` и список `credential_fields`.
   Если сервис выдаёт токен в cookie, задайте `browser_login`, и кнопка входа появится сама.
2. Добавьте класс в `AVAILABLE` в `sonar/services/__init__.py`.

Карточка в «Интеграции», полки на главной и «Моя волна» подхватят его автоматически.

    main.py                    точка входа
    sonar/config.py            config.json в %APPDATA%
    sonar/workers.py           фоновые задачи (сеть не блокирует интерфейс)
    sonar/services/base.py     интерфейс сервиса, модели Track/Section
    sonar/services/soundcloud.py
    sonar/services/youtube_music.py
    sonar/services/spotify.py
    sonar/services/youtube_match.py  подбор трека на YouTube для Spotify
    sonar/services/navidrome.py
    sonar/services/yandex.py
    sonar/services/deezer.py
    sonar/ui/main_window.py    окно, боковая панель, уведомления
    sonar/ui/home.py           главная: «Моя волна» и полки
    sonar/ui/settings.py       Настройки: интеграция, визуальное отображение
    sonar/ui/history_page.py   «Прослушанное»
    sonar/history.py           хранение истории
    sonar/library.py           «Мои лайки» и общая сериализация треков
    sonar/downloads.py         скачанные треки Navidrome
    sonar/ui/service_page.py   страница одного сервиса
    sonar/ui/library_pages.py  исполнители, альбомы, профиль исполнителя, альбом
    sonar/ui/video_bg.py       видео на фоне большого плеера
